How it works

Three steps from graph to answer

01
Build the graph

Each airport is a node; each direct flight is a directed edge.

02
Compute transitive closure

Warshall's triple loop tests every possible intermediate airport.

03
Read the answer

A 1 in the reachability matrix means a route exists.
